## Method and measurement source



* Script: `_measure_attrib.py` (untracked, local only). It builds the graph directly with an `AttributionHandler` callback, the same pattern as the baseline measurement, then calls `propagate("NVDA", "2026-01-09")`.

* The handler records each call on `on_chat_model_start` / `on_llm_start`: call index, owner label, model, tags and metadata; on `on_llm_end` it reads `usage_metadata` (`input_tokens`, `output_tokens`), falling back to `llm_output.token_usage`.

* Owner label: the react agent's internal `langgraph_node` is the generic `agent`, so the owning analyst name is recovered from the `checkpoint_ns` prefix (format `<Analyst Name>:<uuid>`).

* Measurement-only guard, same as the after-build runs: `request_timeout = 60`, `max_retries = 1`, 180 s watchdog. The guard did not trigger.

* Source: callback `usage_metadata`, not the CLI live panel (the panel undercounts, per the 2026-11-13 record).

## Observations and hand-off for B/C



1. **The Market Analyst tool loop is the largest single consumer (24.2%).** Its input climbs 1,952 → 9,786 → 19,461 across three turns; turn 7 alone is 19.5k input, the biggest single call in the run. Fundamentals and News show the same climb. Likely levers for implementation: trim or summarize tool payloads before they are re-fed into the next turn, cap react turns, and identify which tool returns the large dataset.

2. **Risk trio and researchers each receive a full upstream copy.** Every risk analyst starts from 9.1k–14.8k input tokens; Bear Researcher from 12.3k. A shared upstream digest, or confirmation that the existing `compaction_threshold_tokens = 19200` actually reaches these nodes, would cut repeated input.

3. **Output is not the priority.** The largest per-node output is 3.3k tokens; output was flat across the baseline and after-build series. Reduction work should target input context, not reply length.

## Caveats



* One diagnostic run only; shares and per-node totals will vary between runs. This table points to where to look, not a fixed budget per node.

* Owner labels were recovered from `checkpoint_ns` because the react agent exposes a generic `agent` node; the harness has been patched to emit these names directly in future runs.

* The frozen baseline configuration was unchanged for this run; no prompt, analyst set, or round count was edited to reduce tokens.
